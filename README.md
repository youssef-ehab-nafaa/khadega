# خديجة | رزقنا الله بمولودتنا

صفحة احتفال بميلاد خديجة في 3 أكتوبر 2026. الموقع صفحة ثابتة بالعربية والإنجليزية، من HTML وCSS وJavaScript، ويعمل بدون قاعدة بيانات أو خطوة بناء.

## المعاينة

افتحوا `index.html` مباشرة، أو شغّلوا أي خادم ثابت داخل هذا المجلد.

## تعديل المحتوى

لحظة الميلاد الرسمية في `KHADIJA_BIRTH_DATE` بأعلى `script.js`: `2026-10-03T09:00:00` بتوقيت القاهرة.

- `gallery` صور خديجة داخل `assets/images/khadija/`.
- التهاني المشتركة في `data/wishes.json`. الصفحة تقرأ هذا الملف فقط. الإضافة تتم عبر GitHub Actions (`khadija-wish`) حتى لا يوضع مفتاح المستودع في الموقع.
- `websiteUrl` رابط الموقع بعد النشر، حتى تعمل المشاركة والنسخ بشكل صحيح.
- الدعاء يُقرأ بصوت المتصفح عند فتح الصفحة إن سمح، ومن أول لمسة إن مُنع التشغيل التلقائي.

نصوص الواجهة العربية والإنجليزية في `translations`.

## الصور

صور خديجة في `assets/images/khadija/` بصيغة WebP، مع نسخة أصغر لكل صورة. صورة الواجهة: `hero.webp`. صورة المشاركة: `assets/images/og-cover.jpg`.

## النشر

ارفعوا محتويات المجلد إلى فرع `main` ثم فعّلوا GitHub Pages من المجلد الجذر. بعد ذلك ضعوا العنوان النهائي في `celebration.websiteUrl`.

لا تنشروا صورًا أو موسيقى إلا بموافقتكم، ولا تضعوا أرقام هواتف أو بيانات خاصة.
